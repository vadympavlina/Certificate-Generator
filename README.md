# ITSTEP — Генератор сертифікатів

Статичний вебзастосунок для генерації PDF-сертифікатів: один сертифікат або
пакетно з таблиці (ZIP). Усе відбувається у браузері — файли й дані студентів
нікуди не надсилаються.

## Можливості

- **Вбудований дизайн** або **власний PDF-шаблон** з візуальним редактором полів
  (ПІБ, період, грейд, дата, номер): клік або перетягування, прилипання до
  центру/третин/інших полів, розмір, колір, жирність, вирівнювання, точні
  координати в pt, клавіатура (стрілки, Shift, Del, Esc), сенсорні екрани.
- Маркери в редакторі показують текст тим самим шрифтом і розміром, що й у PDF.
- **Пакетна генерація** з `.xlsx / .xls / .ods / .csv` — колонки `name`, `period`,
  `grade` або українські назви (`ПІБ`, `Прізвище та ім'я`, `Період`, `Грейд`,
  `Рівень`…). Рядки з порожніми полями підсвічуються.
- Окремі шаблони та розміщення для вкладок «Один» і «Пакетна» + копіювання між ними.
- Пресети розміщення (JSON) — координати нормалізовані, тож пресет переноситься
  між шаблонами різного розміру.
- Дата видачі й номер сертифіката налаштовуються; номер зберігається в браузері
  (`localStorage`) і збільшується лише після успішного завантаження.
- Шаблони з `/Rotate` та зміщеним CropBox, захищені паролем PDF — зрозуміле повідомлення.
- Повна кирилиця (DejaVu Sans, вбудовується лише підмножина гліфів — ~10 КБ на файл).
- Світла й темна тема (за налаштуваннями системи), адаптивна верстка, повна робота з клавіатури.

## Запуск

Потрібен будь-який статичний HTTP-сервер (через `file://` браузер не дасть
завантажити шрифти й воркер pdf.js):

```bash
npm run serve          # або: python3 -m http.server 8080
```

Відкрийте <http://localhost:8080>. Для GitHub Pages достатньо опублікувати
корінь репозиторію.

## Розробка

```bash
npm install
npm test               # тести ядра (node:test + pdf-lib + pdf.js)
npm run vendor         # оновити vendor/ після зміни версій у package.json
```

| Файл | Призначення |
|---|---|
| `index.html`, `style.css` | розмітка та стилі |
| `script.js` | інтерфейс: вкладки, редактор, перегляд, генерація |
| `cert-core.js` | логіка без DOM: побудова PDF, геометрія сторінки, транслітерація, пресети, розбір таблиць |
| `fonts/` | DejaVu Sans (+ ліцензія) |
| `vendor/` | pdf-lib, fontkit, pdf.js, JSZip (див. `vendor/README.md`) |
| `tests/` | тести `cert-core.js` |

### Безпека

- Дані з таблиць і пресетів ніколи не вставляються як HTML.
- pdf.js відкриває шаблони з `isEvalSupported: false` (CVE-2024-4367).
- SheetJS 0.20.3 (виправлені CVE-2023-30533, CVE-2024-22363) завантажується
  з офіційного CDN лише при відкритті таблиці; решта бібліотек — локальні.
- Content-Security-Policy дозволяє скрипти лише з власного домену та `cdn.sheetjs.com`.
